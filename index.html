주요 기능

로그인 후 왼쪽 사이드바에서 바로 접근할 수 있는 핵심 기능입니다.

조직도

부서 트리에서 동료를 검색하고, 더블클릭으로 바로 대화를 시작합니다. "온라인"만 모아보는 필터도 지원합니다.

대화(채팅)

1:1·그룹 채팅, 파일 전송, @멘션을 지원합니다. 즐겨찾기·알림 끄기·폴더로 정리할 수 있습니다.

알림

멘션·공지를 한 곳에서 확인합니다.

쪽지

받은쪽지함·보낸쪽지함으로 관리합니다.

일정

일반·기간·반복 일정을 등록합니다.

메모장

입력 중 자동으로 저장됩니다.

설치하기

회사에서 안내한 다운로드 링크에서 설치 파일을 받아 실행하면 됩니다.

1
Mac — .dmg 파일을 다운로드한 후 열어서 앱을 Applications 폴더로 드래그하세요.
2
Windows — Setup .exe 파일을 다운로드한 후 실행해서 설치하세요. (일반 PC는 x64, Windows on ARM은 arm64)
3
설치 후 앱을 실행하면 로그인 화면이 나타납니다. 회사에서 안내한 계정으로 로그인하세요.
macOS에서 "손상되었기 때문에 열 수 없습니다" 경고가 뜰 때
아직 앱 서명이 적용되지 않아 나타나는 정상적인 경고입니다. 터미널에서 xattr -cr /Applications/앱이름.app 를 실행한 뒤 다시 실행하면 됩니다. 자세한 내용은 사용자 가이드를 참고하세요.

운영·유지보수 한눈에 보기

서버 설치, 클라이언트 빌드·배포, 자동 업데이트, 장애 대응까지 관리자가 알아야 할 내용을 정리했습니다.

서버 (API + PostgreSQL)

Docker Compose로 DB·API 서버를 한 번에 실행합니다. LDAP 연동, 거래처 조직 동기화 등 선택 기능을 지원합니다.

클라이언트 빌드·배포

macOS(.dmg)/Windows(.exe) 설치 파일을 빌드해 GitHub Releases로 배포합니다. 설치된 앱은 자동으로 최신 버전을 내려받습니다.

사용자·조직 관리

관리자 계정은 설정 패널에서 사용자 등록, 부서·직급 관리, 비밀번호 초기화를 바로 처리할 수 있습니다.

장애 대응

흰 화면, 알림 미수신, DB 연결 오류 등 자주 발생하는 문제와 점검 방법을 정리했습니다.

자주 묻는 질문

더 많은 질문은 사용자 가이드의 FAQ 섹션에서 확인할 수 있습니다.

로그인이 안 돼요.+

아이디/비밀번호를 다시 확인하고, 그래도 안 되면 관리자에게 계정 상태 확인을 요청하세요.

알림이 안 와요.+

Mac은 시스템 설정 → 알림에서 앱 알림 허용 여부를 확인하세요. Windows는 앱 내 알림 설정과 시스템 알림 설정을 함께 확인하세요.

앱이 최신 버전으로 안 바뀌어요.+

앱을 완전히 종료했다가 다시 실행해 보세요. 실행 중 백그라운드로 새 버전을 받아 두었다가 재시작 시 적용됩니다.

조직도에서 특정 부서에 아무도 안 보여요.+

"온라인" 필터가 켜져 있으면 접속 중인 사람이 없는 부서는 목록에서 숨겨집니다. 꺼서 전체 조직도를 확인하세요.
